# Web_Phone

Web_Phone là một dự án web giúp người dùng giả lập giao diện điện thoại trên trình duyệt.

## Tính năng

- Hiển thị giao diện người dùng giống như một chiếc điện thoại di động.
- Tương tác với các thành phần trên giao diện: bấm, kéo thả, nhập liệu, v.v.
- Thiết kế responsive, hoạt động tốt trên nhiều kích thước màn hình.
- Dễ dàng tùy biến mã nguồn.

## Công nghệ sử dụng

- **JavaScript**: Xây dựng logic và các chức năng tương tác.
- **CSS**: Thiết kế giao diện, hiệu ứng, bố cục.
- **HTML**: Cấu trúc trang web.

## Cài đặt và sử dụng

### 1. Tải mã nguồn

Clone repo về máy tính của bạn:

```bash
git clone https://github.com/thuhang2209/Web_Phone.git
cd Web_Phone
```

### 2. Khởi chạy dự án

Mở file `index.html` bằng trình duyệt web (Chrome, Firefox, v.v.):

- Nhấn đúp chuột vào file `index.html`, hoặc
- Chạy với server cục bộ (ví dụ: sử dụng [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) trên VSCode).
